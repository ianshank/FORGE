## Capturing the baselines

```bash
# Random-action baseline (untrained policy, MCTS bypassed)
python -m forge.training.muzero_mc.cli capture-baseline \
    --variant random --episodes 100 \
    --out baseline_random.json

# Trained baseline (continuous-trainer-fed policy, MCTS active)
python -m forge.training.muzero_mc.cli capture-baseline \
    --variant trained --episodes 100 \
    --out baseline_trained.json
```

## Baseline numbers (auto-generated by `mc_plot_baseline.py`)

```bash
python scripts/mc_plot_baseline.py \
```

## Next steps for Phase 2

- Resource-acquisition + milestone reward shapers (currently the
  composite reward only sums survival/inventory/distance/health
  deltas; richer signals like "first wood" or "first stone tool"
  give the planner a more useful gradient).
- Embedding tables for block-IDs (replace `block_type_hash` mod-N
  with a learned lookup so the CNN sees a richer per-tile signal).
- Curriculum controller wiring
  (`python/forge/mangomas/curriculum_controller.py`).
- HuggingFace pretrained-checkpoint loader for warm-starts so the
  trained variant doesn't have to start from random init.
